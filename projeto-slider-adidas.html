01 / 04

Visão geral

O projeto simula a apresentação de três produtos em uma landing page. O recurso central é um slider acionado por setas, que coordena a entrada e a saída dos elementos visuais.

Destaques da entrega

  • Apresentação de três modelos de tênis.
  • Controles para alternar produtos.
  • Animações de entrada e saída com CSS Keyframes.

02 / 04

Contexto e escopo

O objetivo foi praticar design de interface e animação front-end em uma proposta fictícia de apresentação de produtos.

Meu papel e escopo

Implementei a interface e tratei as imagens dos produtos. A Adidas é a referência visual de uma proposta fictícia, realizada como exercício de estudo.

Objetivos e requisitos

  • Apresentar três modelos em uma composição visual consistente.
  • Alternar os produtos com controles de navegação.
  • Coordenar animações de entrada e saída.

03 / 04

Decisões e processo

03.1

Preparação das imagens

Problema
As imagens dos produtos precisavam integrar-se à composição da página.
Abordagem
Tratei as imagens dos produtos no Photoshop para integrá-las às composições da página.
Critério
O tratamento visual prepara as imagens para o mesmo contexto de apresentação.
Efeito na entrega
Cada modelo ocupa a área visual destinada ao produto.
03.2

Estados do carrossel

Problema
O controle de navegação precisava selecionar o produto exibido.
Abordagem
Utilizei JavaScript e manipulação do DOM para alternar o produto exibido.
Critério
A mudança de estado concentra a relação entre ação e item apresentado.
Efeito na entrega
O slider alterna entre os três modelos.
03.3

Transições

Problema
A entrada de um produto precisava acompanhar a saída do anterior.
Abordagem
Coordenei CSS Keyframes com as mudanças de estado para sincronizar a entrada e a saída dos elementos.
Critério
Coordenar a animação com a mudança de estado evita tratar os movimentos como ações independentes.
Efeito na entrega
As transições apresentam a troca do produto em uma sequência visual.
