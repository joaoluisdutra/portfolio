01 / 04

Visão geral

O exercício organiza uma homenagem em uma página web com título, imagem, conteúdo e link de referência. O foco foi a hierarquia das informações e o atendimento aos requisitos estruturais da plataforma.

Destaques da entrega

  • Conteúdo organizado com HTML semântico.
  • Imagem adaptada à largura disponível.
  • Identificadores e link de referência previstos pelo exercício.

02 / 04

Contexto e escopo

O projeto foi realizado na certificação de Design para web Responsivo da freeCodeCamp, com requisitos definidos para estrutura e identificação dos elementos.

Meu papel e escopo

Minha contribuição foi implementar a estrutura HTML e a adaptação visual com CSS, seguindo os requisitos do exercício da freeCodeCamp.

Objetivos e requisitos

  • Identificar os elementos exigidos pelo exercício.
  • Adaptar a imagem e o conteúdo à largura disponível.
  • Organizar o texto e o link de referência com uma hierarquia clara.
Continuar: Decisões e processo →︎

03 / 04

Decisões e processo

03.1

Estrutura exigida

Problema
O exercício exigia elementos identificáveis pela plataforma.
Abordagem
Implementei os identificadores #main, #title, #image e #tribute-link previstos no exercício.
Critério
IDs explícitos relacionam a estrutura aos requisitos do exercício.
Efeito na entrega
O HTML utiliza #main, #title, #image e #tribute-link.
03.2

Adaptação da imagem

Problema
A imagem precisava acompanhar a largura disponível.
Abordagem
Utilizei CSS responsivo para ajustar a imagem à área disponível.
Critério
Regras responsivas permitem ajustar sua apresentação ao layout.
Efeito na entrega
A imagem se integra à área de conteúdo da página.
03.3

Hierarquia de conteúdo

Problema
Título, imagem, texto e referência precisavam formar uma sequência de leitura.
Abordagem
Organizei os elementos estruturais para apresentar o conteúdo da homenagem em uma sequência legível.
Critério
A organização estrutural distingue o papel de cada elemento.
Efeito na entrega
O conteúdo da homenagem é apresentado em uma hierarquia.
