Visão geral

A experiência transforma uma composição estática em uma página que reage ao cursor e à rolagem. Os blocos mudam de proporção, as formas flutuam e as seções se sobrepõem durante a exploração do conteúdo.

Contexto e escopo

O exercício da Awwwards Academy propôs uma experiência visual construída com tecnologias nativas da web, sem frameworks.

Meu papel e escopo

A formação na Awwwards Academy orientou o desenvolvimento. Minha responsabilidade foi implementar o front-end; apresento o trabalho como exercício educacional sob orientação de Yannick Gregoire.

Desafio de implementação

Relacionar a posição do cursor às proporções do layout e coordenar essa resposta com as transições. O código utiliza um evento mousemove, enquanto o CSS controla a duração e a curva do movimento.

03 / 04

Decisões e processo

03.1

Transformar o cursor em proporção do layout

Problema
Os blocos precisavam reagir à posição do visitante na tela.
Abordagem
O evento mousemove atualiza flexBasis: clientX determina a largura do bloco vazio, clientY / 2 influencia o título e innerWidth − clientX define a área das figuras.
Critério
A mesma coordenada permite relacionar as áreas da composição por meio do Flexbox.
Efeito na entrega
O espaço destinado a texto e imagem muda com o movimento do cursor.
function handleMouseMove(event) {
    emptyElement.style.flexBasis = event.clientX + 'px';
    titleElement.style.flexBasis = event.clientY / 2 + 'px';
    figureElements.forEach(function (element) {
        element.style.flexBasis =
            window.innerWidth - event.clientX + 'px';
    });
}

03.2

Suavizar a resposta e manter o movimento no CSS

Problema
Uma alteração imediata das proporções produziria uma mudança brusca entre posições.
Abordagem
O CSS aplica uma transição de um segundo a flex-basis com cubic-bezier(0,.9,.4,.99). A animação float alterna translateY de −5% a 5% nas formas.
Critério
O script fornece a dimensão e o CSS define o tempo e a curva do movimento.
Efeito na entrega
A composição acompanha o cursor gradualmente; as formas flutuam de maneira independente.
transition: flex-basis 1s cubic-bezier(0,.9,.4,.99);

@keyframes float {
    0%   { transform: translateY(-5%); }
    100% { transform: translateY(5%); }
}

03.3

Relacionar a rolagem à composição das seções

Problema
A leitura precisava revelar as seções em uma sequência visual e acomodar a área de figuras em telas menores.
Abordagem
As seções utilizam position: sticky e top: 100px. A regra de até 768px muda os artigos de serviços para flex-direction: column e a área das figuras para flex-basis: 25vh.
Critério
Sticky relaciona a composição à rolagem nativa; a disposição em coluna permite reorganizar figura e texto no breakpoint.
Efeito na entrega
As seções se sobrepõem durante a rolagem e os serviços passam a apresentar figura e texto em sequência vertical em telas menores.

04 / 04

Resultados e retrospectiva

Entrega e aprendizado

A entrega reúne a página implementada, o código publicado e a demonstração em vídeo. O projeto exercitou a relação entre coordenadas do cursor e propriedades do layout, além da divisão entre o cálculo de dimensões no JavaScript e a temporização no CSS.

Evidências examinadas

Os trechos e as duas capturas desta página foram extraídos do código publicado: as posições x = 450 px e x = 800 px mostram a alteração do bloco vazio. A folha de estilos registra o breakpoint de 768px, a sobreposição sticky e a animação float.

Próxima etapa

A próxima evolução é limitar a resposta ao cursor a dispositivos com apontador, oferecer movimento reduzido e testar a leitura e a navegação em telas menores. Também cabe comparar alternativas ao uso de flex-basis animado, medindo o custo de layout.
