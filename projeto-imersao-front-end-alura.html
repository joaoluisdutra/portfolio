02 / 04

O que foi desenvolvido

O projeto foi desenvolvido para a Imersão Front-End Alura e busca recriar a experiência da página inicial do Spotify, replicando seu layout e funcionalidade para estudo e prática de desenvolvimento web. Os cards de recomendação foram desenvolvidos para serem dinâmicos e responsivos, imitando a forma como o serviço oficial personaliza o conteúdo para o usuário.

O objetivo central foi demonstrar a capacidade de replicar interfaces complexas, com foco na organização visual e na adaptabilidade do design para diferentes dispositivos, garantindo uma experiência de navegação fluida e intuitiva.

03 / 04

Aprendizados e Técnicas

O processo iniciou-se com a criação da estrutura semântica em HTML e a estilização avançada com CSS para atingir a fidelidade visual da marca. O comportamento dinâmico da barra de pesquisa foi implementado com JavaScript, permitindo interações em tempo real.

Um ponto técnico relevante foi o uso de um arquivo .json para armazenar e gerenciar os dados dos artistas. Através da manipulação do DOM, os resultados são filtrados e exibidos dinamicamente conforme o usuário interage com a busca, simulando o comportamento de uma aplicação real consumindo uma API.
